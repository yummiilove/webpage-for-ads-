# Little Wins Club

A lightweight, responsive lifestyle website with a warm editorial design and small interactive tools.

## Run it locally
1. Extract the ZIP.
2. Open `index.html` in a browser. No build step is required.
3. For a public website, upload the contents of this folder to a static host such as GitHub Pages, Netlify, or your own hosting.

## Before publishing
- Replace `https://example.com/` in `index.html` with your real canonical URL.
- Update the contact page with an email address you control.
- Review and update `privacy.html` for the exact analytics, cookies, advertising partners, and consent requirements you use.
- Add original, useful articles and keep publishing helpful content. A polished homepage alone does not guarantee ad-network approval or meaningful earnings.
- Replace the ad placeholder in `index.html` with ad code only after your ad network approves the site. Keep ads clearly labeled, and never ask or incentivize visitors to click ads.
- If you use a domain, update the favicon, metadata, and any other references as needed.

## Files
- `index.html` — main website
- `styles.css` — responsive design
- `script.js` — mood ideas, journal prompts, and local habit tracker
- `about.html`, `privacy.html`, `contact.html` — supporting pages
- `favicon.svg` — browser icon

## Notes
The habit tracker saves only in the visitor's current browser using local storage. There is no database, login, backend, or newsletter collection.
